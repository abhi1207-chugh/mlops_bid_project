           Annexure – I: Technical Specification of the Network Switches
A. Technical Specification for 48 port Non-POE Gigabit Layer-2 managed switch with 10G fiber
   uplink ports (Qty: 35)

   1. Should be rack mountable.
   2.  Should have minimum one internal PSU and two internal fans.
   3.  Should have minimum 48 x 1G copper/RJ45 ports.
   4.  Should have minimum 4 x 10G SFP+ ports.
   5.  Should have built-in USB port to facilitate upload/download of configuration files and
       Firmware updates.
   6. Should support dual firmware image architecture.
   7. Should have non-blocking architecture with minimum 176 Gbps switching fabric/bandwidth
       and minimum 130.9 Mpps packet forwarding rate.
   8. Should support minimum 256 VLANS, 16K MAC addresses database size and 512 Multicast
       groups.
   9. Should support advanced features such as IPv4/IPv6 static routing, DHCP snooping and VLAN
       routing.
   10. Should support services such as Broadcast, Multicast and unknown Unicast storm control, STP
       (Rapid STP & Multiple STP) and DHCP Relay.
   11. Should support 802.1x RADIUS Network Access Control, L2/L3 ACLs, DoS attacks
       prevention, Network Storm protection and Dynamic ARP inspection.
   12. Should support Voice VLAN with SIP protocol and LLDP-MED IP phones.
   13. Operating Temperature should be from 0° to 50°C (32° to 122°F).


B. Technical Specification for 24 port Non-POE 10Gigabit Layer-3 managed switch with 10G
   fiber uplink ports (Qty: 03)

   1.  Should be rack mountable.
   2.  Should have minimum one internal PSU and two internal fans.
   3.  Should have minimum 12 x 1G/2.5G/5G/10G copper/RJ45 ports.
   4.  Should have minimum 12 x 1G/10G SFP+ ports.
   5.  Should have built-in USB port to facilitate upload/download of configuration files and
       Firmware updates.
   6. Should support dual firmware image architecture.
   7. Should have non-blocking architecture with minimum 480 Gbps switching fabric/bandwidth
       and minimum 350 Mpps throughput.
   8. Should support minimum 4K VLANS, 16K MAC addresses database size, 4K (IPv4 + IPv6)
       Multicast groups and L2/L3 100 ACLs.
   9. Should support advanced features such as IPv4/IPv6 static routing, DHCP snooping and VLAN
       routing.
   10. Should support services such as Broadcast, Multicast and unknown Unicast storm control, STP
       (Rapid STP & Multiple STP) and DHCP Relay.
   11. Should support 802.1x Radius Port Access Authentication, L2/L3 ACLs, DoS attacks
       prevention, Network Storm protection and Dynamic ARP inspection.
   12. Should support Voice VLAN with SIP protocol and LLDP-MED IP phones automatic QoS and
       VLAN configuration.
   13. Operating Temperature should be from 0° to 50°C (32° to 122°F).
